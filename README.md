# Kumo ☁️ — Your Travel Archive

A personal travel operating system. Plan trips, capture experiences, preserve memories, and build a lifelong travel archive.

## What's inside

```
kumo/
├── index.html     # The entire app (self-contained)
├── vercel.json    # Vercel deployment config
└── README.md      # This file
```

## Deploy

This is a self-contained static HTML app — no build step, no dependencies, no npm install.

### Via GitHub + Vercel

1. Push this repo to GitHub
2. Go to [vercel.com/new](https://vercel.com/new)
3. Import your GitHub repo
4. Vercel will auto-detect the static site — click **Deploy**

That's it. No framework preset needed. No build command. No output directory to configure.

### Manual deploy (Vercel CLI)

```bash
npm i -g vercel
vercel --prod
```

## Features

- 🏠 Trip dashboard with countdown, weather, budget, memories
- 📅 Itinerary management (day-by-day)
- 📍 Places — wishlist, planned, visited, reserved
- 🏨 Stays — hotel bookings and confirmations
- 🚄 Transport — flights, trains, buses
- 🗺 Routes — optimized day plans
- 💰 Finance — budget tracking and expense logging
- 📂 Documents — centralized file storage
- 📸 Memories — photo journal with ratings and Future-Me notes
- 📖 Travel journal — longform daily entries
- 🎖 Passport — country stamps and achievements
- 🎁 Travel Wrapped — year-in-review summary
- 🔍 Global search across everything
- ⚙️ Settings — light/dark mode, accent colors, data export

## Tech

Pure HTML, CSS, JavaScript. No frameworks. No dependencies. No build step.
